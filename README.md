# Simple Interest Calculator

Repository: `github-final-project`

This project provides a Bash calculator that computes simple interest from the principal amount, annual rate of interest, and time period in years.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output:
   simple interest = p*t*r/100
```

Run the calculator with:

```bash
bash simple-interest.sh
```
